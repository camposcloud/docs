---
title: '/v1/apps/{appId}/start'
description: 'This endpoint starts an application by its ID.'
openapi: 'POST /v1/apps/{appId}/start'
---

<Warning>
  Starting an application that is already running returns `500`. Check `currentResourceMetrics.online` first.
</Warning>

<Tip>
  The application is offline and you did not stop it? See [why an application stopped](/guides/why-an-application-stopped).
</Tip>
