---
title: '/v1/apps/{appId}/logs'
description: 'This endpoint streams the console of an application in real time, read-only.'
openapi: 'GET /v1/apps/{appId}/logs'
---

<Warning>
  At most 5 streams can be open at the same time per account, and at most 20 new connections can be opened per minute. Close the streams you no longer need.
</Warning>

<Note>
  This endpoint is read-only: it only sends the output of the application. There is no way to send input or commands to the application through it.
</Note>

## How the stream behaves

1. When the stream opens you receive `ready`, then `clear` and the last `tail` lines (100 by default).
2. After that, every new line arrives as a `log` event as soon as the application writes it.
3. When the application stops or starts you receive `status` with `die` or `start`. After a start you receive `clear` and the first lines of the new run.
4. The server closes every stream after 30 minutes with `end` and `reason: "timeout"`, and also when it loses the connection to the server that runs the application (`worker-lost`) or when your client reads too slowly (`slow-client`). Reconnect when that happens; the permissions are checked again on every connection.

<Tip>
  Always handle `clear` by discarding what you have shown. That is how you avoid showing the same lines twice after a reconnection.
</Tip>

## Examples

<CodeGroup>

```bash curl
curl -N "https://api.camposcloud.com/v1/apps/<appId>/logs?tail=50" \
  -H "Authorization: Bearer <token>"
```

```javascript Node.js 18+
const response = await fetch("https://api.camposcloud.com/v1/apps/<appId>/logs?tail=50", {
  headers: { Authorization: "Bearer <token>", Accept: "text/event-stream" },
});
if (!response.ok) throw new Error((await response.json()).error);

const decoder = new TextDecoder();
let buffer = "";
for await (const chunk of response.body) {
  buffer += decoder.decode(chunk, { stream: true });
  let end;
  while ((end = buffer.indexOf("\n\n")) >= 0) {
    const block = buffer.slice(0, end);
    buffer = buffer.slice(end + 2);
    let event = "message";
    const data = [];
    for (const line of block.split("\n")) {
      if (line.startsWith("event:")) event = line.slice(6).trim();
      else if (line.startsWith("data:")) data.push(line.slice(5).replace(/^ /, ""));
    }
    if (data.length === 0) continue; // comments such as ": ping"
    if (event === "clear") console.clear();
    else if (event === "log") console.log(data.join("\n"));
    else if (event === "end") console.log("stream ended:", JSON.parse(data.join("\n")).reason);
  }
}
```

```python Python (requests)
import json
import requests

url = "https://api.camposcloud.com/v1/apps/<appId>/logs"
headers = {"Authorization": "Bearer <token>", "Accept": "text/event-stream"}

with requests.get(url, headers=headers, params={"tail": 50}, stream=True, timeout=(10, 70)) as response:
    response.raise_for_status()
    event, data = "message", []
    for line in response.iter_lines(decode_unicode=True):
        if line == "":
            if data:
                text = "\n".join(data)
                if event == "log":
                    print(text)
                elif event == "end":
                    print("stream ended:", json.loads(text)["reason"])
            event, data = "message", []
        elif line.startswith("event:"):
            event = line[6:].strip()
        elif line.startswith("data:"):
            data.append(line[5:].removeprefix(" "))
```

<Note>
  The browser `EventSource` API cannot send the `Authorization` header, so call this endpoint from your server or with `fetch`, never from a public web page: that would expose your API token.
</Note>
