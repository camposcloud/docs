---
title: '/v1/apps/{appId}/update'
description: 'This endpoint updates an application by its ID.'
openapi: 'POST /v1/apps/{appId}/update'
---

<Warning>
  This endpoint has a rate limit of 1 request every 3 seconds.
</Warning>

<Note>
  Only the fields you send are changed. Fields that are not listed below (for example `team`) are rejected with `400`.
</Note>

<Note>
  Most changes are not applied immediately: the response comes back with `restartRequired: true` and the new settings take effect the next time the application is started or restarted.
</Note>

<Warning>
  `environmentVariables` replaces the whole list. Omit the field to keep the current variables; send `[]` to remove all of them. A variable with an empty `value` makes the request fail with `500`.
</Warning>

<Tip>
  `buildCommand` runs after the dependencies are installed and before `startupCommand`; send `""` to remove it. Changing `mainFile` also updates a start command that was the default of the runtime (for example `node index.js`); a start command you wrote stays as it is.
</Tip>

<Note>
  A custom domain (`assignedCustomDomain`) is not routed right away. The response brings `customDomainPending`, `customDomainTxtName` and `customDomainTxtValue`: publish that TXT record in your DNS and confirm with [`POST /v1/apps/{appId}/custom-domain/verify`](/api-reference/endpoint/v1/applications/verifyDomain).
</Note>
