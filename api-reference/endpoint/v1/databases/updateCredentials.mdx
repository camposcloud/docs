---
title: '/v1/databases/{databaseId}/update-credentials'
description: 'This endpoint replaces the password of a database.'
openapi: 'POST /v1/databases/{databaseId}/update-credentials'
---

<Warning>
  This endpoint has a rate limit of 1 request every 3 seconds, shared with the other endpoints that change databases (create, update, update credentials and delete).
</Warning>

<Warning>
  Applications that use the old password stop connecting until you update them.
</Warning>
